# ADR-0001: 벡터 저장소는 pgvector로 설치만 하고 확정은 Phase 4에서

- 상태: 보류(설치만 완료)
- 결정: Postgres 이미지를 `pgvector/pgvector:pg16`로 쓰고 `vector` 확장을 만든다. 실제 사용 여부는 Phase 4 시작 시 결정한다.
- 이유: 운영 대상을 늘리지 않고(별도 벡터 DB 없음) 백업·권한 체계를 하나로 유지할 수 있다.
- 대안: Qdrant 등 별도 벡터 DB. 대규모 데이터에선 유리하나 이 프로젝트 규모(조항 수천~수만)에서는 운영 부담이 더 크다.
- 재검토 조건: 임베딩 차원·검색 지연이 평가 기준을 못 맞출 때.
