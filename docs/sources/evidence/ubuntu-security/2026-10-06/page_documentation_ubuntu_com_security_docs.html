Ubuntu security documentation¶

Ubuntu prioritizes security through its core principles. It is a transparent, secure-by-design, and secure-by-default platform. Your Ubuntu software benefits from the latest security technologies and long-term maintenance, allowing you to build a strong security posture.

Canonical offers comprehensive services, including regular security updates and system hardening tools based on industry standards, to support Ubuntu’s built-in security features. Understanding how these function ensures your Ubuntu deployments stay secure according to your needs.
